## C3D PRO

O **C3D PRO** é uma plataforma de gestão desenvolvida para makers, profissionais e pequenos negócios de impressão 3D.

Centraliza num único sistema tudo o que precisas para controlar o negócio:

- 🏭 Produção e impressoras
- 📦 Stock e materiais
- 👥 Gestão de clientes
- 💰 Custos e margens
- 📄 Orçamentos e documentos
- 📊 Dashboard e indicadores
- 📈 Relatórios profissionais
- 🔄 Atualizações integradas

## Atualizações automáticas

A partir das versões compatíveis, o próprio C3D PRO pode verificar novas versões através de:

**Ajuda → Procurar atualizações**

Quando existir uma nova versão, a aplicação permite descarregar o instalador oficial e validar a integridade do ficheiro antes da instalação.
